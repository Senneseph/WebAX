# Lost Device Handling

## Introduction

Lost or stolen devices pose a significant security risk in device-based authentication systems. Effective lost device handling procedures ensure that users can quickly and securely respond to device loss, protecting their data and maintaining access to their applications.

## Lost Device Scenarios

There are two primary scenarios for lost devices, each requiring different handling:

1. **Non-Owner Device Lost**: A paired device other than the owner device is lost
2. **Owner Device Lost**: The owner device itself is lost

## Non-Owner Device Handling

When a non-owner device is lost, the process is relatively straightforward:

1. **Revocation**: The owner device revokes access for the lost device
2. **Key Rotation**: New encryption keys are generated
3. **Notification**: Other devices are notified of the revocation
4. **Logging**: The event is logged for security purposes

### Implementation Example

```javascript
async function handleLostDevice(deviceId) {
  // Revoke access for the lost device
  await revokeDeviceAccess(deviceId);
  
  // Log the event
  await logSecurityEvent({
    type: 'device_lost_reported',
    lostDeviceId: deviceId,
    reportedBy: getCurrentDeviceId(),
    timestamp: new Date().toISOString()
  });
  
  // Notify user on all active devices
  const registry = await deviceRegistry.getRegistry();
  const activeDevices = registry.devices.filter(d => d.status === 'active');
  
  await Promise.all(activeDevices.map(device => 
    notifyDeviceOfLostDevice(device, deviceId)
  ));
  
  return {
    success: true,
    message: 'Device access has been revoked'
  };
}

async function notifyDeviceOfLostDevice(device, lostDeviceId) {
  try {
    // Establish secure channel with device
    const channel = await establishSecureChannel(device.id);
    
    // Send lost device notification
    await channel.send({
      type: 'lost_device_notification',
      lostDeviceId,
      timestamp: Date.now()
    });
    
    // Close channel
    channel.close();
    
    return true;
  } catch (error) {
    console.error(`Failed to notify device ${device.id} of lost device:`, error);
    return false;
  }
}
```

## Owner Device Recovery

When the owner device is lost, recovery is more complex since the owner device is needed for many operations:

### Recovery Options

1. **Recovery Key**: Use a pre-generated recovery key to authenticate
2. **Trusted Device**: Transfer ownership to a trusted paired device
3. **Recovery Process**: Authenticate and establish a new owner device

### Recovery Key Generation

During owner device setup, generate and securely store a recovery key:

```javascript
async function generateRecoveryKey() {
  // Generate a random recovery key
  const recoveryKeyBytes = new Uint8Array(16);
  window.crypto.getRandomValues(recoveryKeyBytes);
  
  // Convert to a readable format (4 groups of 5 characters)
  const recoveryKey = Array.from(recoveryKeyBytes)
    .map(b => b.toString(16).padStart(2, '0'))
    .join('')
    .toUpperCase()
    .match(/.{1,5}/g)
    .join('-');
  
  // Hash the recovery key for storage
  const encoder = new TextEncoder();
  const recoveryKeyData = encoder.encode(recoveryKey);
  const recoveryKeyHash = await window.crypto.subtle.digest('SHA-256', recoveryKeyData);
  
  // Convert hash to hex string
  const recoveryKeyHashHex = Array.from(new Uint8Array(recoveryKeyHash))
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
  
  // Store the hash (not the key itself)
  await secureStorage.set('recovery_key_hash', recoveryKeyHashHex);
  
  // Return the recovery key to show to the user
  return recoveryKey;
}
```

### Ownership Transfer

Implement a secure process for transferring ownership to another device:

```javascript
async function initiateOwnerDeviceRecovery(recoveryKey) {
  // Verify recovery key
  const storedRecoveryKeyHash = await secureStorage.get('recovery_key_hash');
  const providedKeyHash = await hashRecoveryKey(recoveryKey);
  
  if (storedRecoveryKeyHash !== providedKeyHash) {
    throw new Error('Invalid recovery key');
  }
  
  // Get current device info
  const currentDeviceMetadata = await deviceRegistry.getCurrentDeviceMetadata();
  
  // Get registry
  const registry = await deviceRegistry.getRegistry();
  
  // Find owner device
  const ownerDevice = registry.devices.find(d => d.isOwner);
  
  if (!ownerDevice) {
    throw new Error('No owner device found in registry');
  }
  
  // Transfer ownership
  ownerDevice.isOwner = false;
  ownerDevice.status = 'revoked';
  ownerDevice.revokedAt = new Date().toISOString();
  
  currentDeviceMetadata.isOwner = true;
  
  // Update current device in registry
  const currentDeviceIndex = registry.devices.findIndex(d => d.id === currentDeviceMetadata.id);
  
  if (currentDeviceIndex >= 0) {
    registry.devices[currentDeviceIndex] = currentDeviceMetadata;
  } else {
    registry.devices.push(currentDeviceMetadata);
  }
  
  // Update registry owner device ID
  registry.ownerDeviceId = currentDeviceMetadata.id;
  
  // Update registry
  await deviceRegistry.updateRegistry(registry);
  
  // Update local device status
  await secureStorage.set('is_owner', 'true');
  
  // Generate new encryption keys
  const newKeys = await generateNewEncryptionKeys();
  
  // Notify other active devices
  const activeDevices = registry.devices.filter(
    d => d.status === 'active' && d.id !== currentDeviceMetadata.id
  );
  
  await Promise.all(activeDevices.map(device => 
    notifyDeviceOfOwnershipTransfer(device, currentDeviceMetadata.id, newKeys)
  ));
  
  // Generate new recovery key
  const newRecoveryKey = await generateRecoveryKey();
  
  // Log the event
  await logSecurityEvent({
    type: 'ownership_transferred',
    previousOwnerId: ownerDevice.id,
    newOwnerId: currentDeviceMetadata.id,
    reason: 'recovery',
    timestamp: new Date().toISOString()
  });
  
  return {
    success: true,
    message: 'Ownership transferred successfully',
    newRecoveryKey
  };
}

async function hashRecoveryKey(recoveryKey) {
  // Normalize the recovery key (remove dashes, uppercase)
  const normalizedKey = recoveryKey.replace(/-/g, '').toUpperCase();
  
  // Hash the recovery key
  const encoder = new TextEncoder();
  const recoveryKeyData = encoder.encode(normalizedKey);
  const recoveryKeyHash = await window.crypto.subtle.digest('SHA-256', recoveryKeyData);
  
  // Convert hash to hex string
  return Array.from(new Uint8Array(recoveryKeyHash))
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
}
```

## Preventive Measures

Implement preventive measures to minimize the impact of lost devices:

### Remote Wipe

Allow users to remotely wipe application data from lost devices:

```javascript
async function initiateRemoteWipe(deviceId) {
  // Check if current device is owner
  const currentDeviceMetadata = await deviceRegistry.getCurrentDeviceMetadata();
  
  if (!currentDeviceMetadata.isOwner) {
    throw new Error('Only the owner device can initiate remote wipe');
  }
  
  // Get device info
  const deviceToWipe = await deviceRegistry.getDeviceById(deviceId);
  
  if (!deviceToWipe) {
    throw new Error('Device not found');
  }
  
  // Create wipe command
  const wipeCommand = {
    type: 'remote_wipe',
    targetDeviceId: deviceId,
    initiatedBy: currentDeviceMetadata.id,
    timestamp: new Date().toISOString(),
    wipeToken: generateUUID()
  };
  
  // Store wipe command for when device comes online
  const pendingWipeCommands = JSON.parse(
    await secureStorage.get('pending_wipe_commands') || '[]'
  );
  
  pendingWipeCommands.push(wipeCommand);
  await secureStorage.set('pending_wipe_commands', JSON.stringify(pendingWipeCommands));
  
  // Try to send wipe command immediately if device is online
  try {
    const channel = await establishSecureChannel(deviceId, 5000); // 5 second timeout
    
    if (channel) {
      await channel.send(wipeCommand);
      channel.close();
    }
  } catch (error) {
    console.log(`Device ${deviceId} is not currently online. Wipe command will be sent when it connects.`);
  }
  
  // Log the event
  await logSecurityEvent({
    type: 'remote_wipe_initiated',
    targetDeviceId: deviceId,
    initiatedBy: currentDeviceMetadata.id,
    timestamp: new Date().toISOString()
  });
  
  return {
    success: true,
    message: 'Remote wipe initiated',
    pendingDelivery: true
  };
}
```

### Automatic Locking

Implement automatic locking after periods of inactivity:

```javascript
function setupAutomaticLocking() {
  let inactivityTimer;
  const INACTIVITY_TIMEOUT = 15 * 60 * 1000; // 15 minutes
  
  // Reset timer on user activity
  function resetInactivityTimer() {
    if (inactivityTimer) {
      clearTimeout(inactivityTimer);
    }
    
    inactivityTimer = setTimeout(() => {
      lockApplication();
    }, INACTIVITY_TIMEOUT);
  }
  
  // Lock the application
  function lockApplication() {
    // Clear sensitive data from memory
    clearSensitiveData();
    
    // Show lock screen
    showLockScreen();
    
    // Log the event
    logDeviceActivity(getCurrentDeviceId(), 'auto_lock', {
      reason: 'inactivity',
      inactivityDuration: INACTIVITY_TIMEOUT
    });
  }
  
  // Set up event listeners for user activity
  ['mousedown', 'keydown', 'touchstart', 'scroll'].forEach(eventType => {
    window.addEventListener(eventType, resetInactivityTimer, true);
  });
  
  // Initial timer setup
  resetInactivityTimer();
}
```

### Backup Recovery Options

Provide multiple recovery options:

1. **Recovery Key**: Primary recovery method
2. **Trusted Contacts**: Allow recovery through trusted contacts
3. **Secondary Email/Phone**: Verify identity through secondary channels

```javascript
async function setupTrustedContactRecovery(contactEmail) {
  // Generate a recovery code for this contact
  const recoveryCode = generateRecoveryCode();
  
  // Hash the recovery code
  const recoveryCodeHash = await hashRecoveryCode(recoveryCode);
  
  // Store the trusted contact info
  const trustedContacts = JSON.parse(
    await secureStorage.get('trusted_contacts') || '[]'
  );
  
  trustedContacts.push({
    email: contactEmail,
    recoveryCodeHash,
    createdAt: new Date().toISOString()
  });
  
  await secureStorage.set('trusted_contacts', JSON.stringify(trustedContacts));
  
  // Send recovery code to the contact
  await sendRecoveryCodeEmail(contactEmail, recoveryCode);
  
  return {
    success: true,
    message: 'Trusted contact added successfully'
  };
}
```

## User Education

Educate users about lost device procedures:

1. **Recovery Key Storage**: Advise on secure storage of recovery keys
2. **Quick Response**: Emphasize the importance of quick response to device loss
3. **Prevention**: Provide tips for preventing device loss
4. **Regular Testing**: Encourage regular testing of recovery procedures
