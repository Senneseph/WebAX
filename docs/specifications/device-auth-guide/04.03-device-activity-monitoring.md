# Device Activity Monitoring

## Introduction

Device activity monitoring provides visibility into how and when devices are accessing the application. This helps users identify suspicious behavior, understand usage patterns, and maintain awareness of which devices are active. Effective activity monitoring balances security with privacy and performance considerations.

## Activity Tracking

### Types of Activities to Track

Track the following types of activities:

1. **Authentication**: When a device authenticates
2. **Data Access**: When a device accesses sensitive data
3. **Synchronization**: When a device syncs data
4. **Settings Changes**: When a device changes settings
5. **Security Events**: Authentication failures, pairing attempts, etc.
6. **Location**: Optional geographic location of activity (with user consent)

### Activity Record Structure

Each activity record should include:

```javascript
{
  id: "activity-uuid-123",         // Unique activity identifier
  deviceId: "device-uuid-123",     // Device that performed the activity
  deviceName: "John's iPhone",     // User-friendly device name
  activityType: "authentication",  // Type of activity
  timestamp: "2023-07-15T14:45:00Z", // When the activity occurred
  details: {                       // Activity-specific details
    // Varies based on activity type
  },
  location: {                      // Optional location information
    country: "United States",
    region: "California",
    city: "San Francisco"
  }
}
```

## Implementation

### Activity Logging

The following function demonstrates how to log device activities:

```javascript
async function logDeviceActivity(deviceId, activityType, details = {}) {
  // Get current device info
  const deviceMetadata = await deviceRegistry.getDeviceById(deviceId);
  
  if (!deviceMetadata) {
    throw new Error('Device not found');
  }
  
  // Create activity record
  const activity = {
    id: generateUUID(),
    deviceId,
    deviceName: deviceMetadata.name,
    activityType,
    timestamp: new Date().toISOString(),
    details,
    // Optional: include approximate location if available and permitted
    location: await getApproximateLocation()
  };
  
  // Store activity in secure storage
  const activities = await getDeviceActivities();
  activities.push(activity);
  
  // Limit size of activity log
  if (activities.length > MAX_ACTIVITY_LOG_SIZE) {
    activities.shift(); // Remove oldest activity
  }
  
  await secureStorage.set('device_activities', JSON.stringify(activities));
  
  // Update device last active timestamp
  await deviceRegistry.updateDeviceLastActive(deviceId);
  
  return activity;
}

async function getDeviceActivities() {
  const activitiesJson = await secureStorage.get('device_activities');
  return activitiesJson ? JSON.parse(activitiesJson) : [];
}
```

### Location Tracking

If including location data, implement it with privacy in mind:

```javascript
async function getApproximateLocation() {
  // Check if location tracking is enabled
  const locationTrackingEnabled = await secureStorage.get('location_tracking_enabled');
  
  if (locationTrackingEnabled !== 'true') {
    return null;
  }
  
  try {
    // Use IP-based geolocation for approximate location
    // This avoids requesting precise GPS coordinates
    const response = await fetch('https://api.ipgeolocation.io/ipgeo');
    const data = await response.json();
    
    return {
      country: data.country_name,
      region: data.state_prov,
      city: data.city
    };
  } catch (error) {
    console.error('Failed to get location:', error);
    return null;
  }
}
```

### Activity Summary

Provide a summary of device activities:

```javascript
async function getDeviceActivitySummary() {
  const activities = await getDeviceActivities();
  const registry = await deviceRegistry.getRegistry();
  
  // Group activities by device
  const deviceSummaries = {};
  
  registry.devices.forEach(device => {
    const deviceActivities = activities.filter(a => a.deviceId === device.id);
    
    deviceSummaries[device.id] = {
      device,
      lastActivity: deviceActivities.length > 0 
        ? deviceActivities[deviceActivities.length - 1] 
        : null,
      activityCount: deviceActivities.length,
      recentActivities: deviceActivities.slice(-5) // Last 5 activities
    };
  });
  
  return deviceSummaries;
}
```

### Anomaly Detection

Implement basic anomaly detection to identify suspicious activities:

```javascript
async function detectAnomalies() {
  const activities = await getDeviceActivities();
  const anomalies = [];
  
  // Check for rapid authentication from different locations
  const authActivities = activities.filter(a => a.activityType === 'authentication');
  
  for (let i = 1; i < authActivities.length; i++) {
    const current = authActivities[i];
    const previous = authActivities[i - 1];
    
    // Check if same device authenticated from different locations in short time
    if (current.deviceId === previous.deviceId && 
        current.location && previous.location &&
        current.location.country !== previous.location.country) {
      
      const timeDiff = new Date(current.timestamp) - new Date(previous.timestamp);
      
      // If less than 24 hours between logins from different countries
      if (timeDiff < 24 * 60 * 60 * 1000) {
        anomalies.push({
          type: 'rapid_location_change',
          severity: 'high',
          deviceId: current.deviceId,
          deviceName: current.deviceName,
          activities: [previous, current],
          timestamp: new Date().toISOString()
        });
      }
    }
  }
  
  // Check for unusual activity times
  const userActivityPattern = await getUserActivityPattern();
  
  activities.forEach(activity => {
    const activityHour = new Date(activity.timestamp).getHours();
    
    // If activity occurs during unusual hours for this user
    if (userActivityPattern[activityHour] < 0.1) { // Less than 10% of normal activity
      anomalies.push({
        type: 'unusual_activity_time',
        severity: 'medium',
        deviceId: activity.deviceId,
        deviceName: activity.deviceName,
        activity,
        timestamp: new Date().toISOString()
      });
    }
  });
  
  return anomalies;
}
```

## Synchronization

Activity logs should be synchronized across devices to provide a complete view of activity:

1. **Selective Sync**: Allow users to choose whether to sync activity logs
2. **Aggregation**: Combine activity logs from all devices
3. **Deduplication**: Remove duplicate activity records
4. **Conflict Resolution**: Handle conflicts when merging activity logs

```javascript
async function syncActivityLogs(remoteActivities) {
  // Get local activities
  const localActivities = await getDeviceActivities();
  
  // Create a map of existing activity IDs for quick lookup
  const existingActivityIds = new Set(localActivities.map(a => a.id));
  
  // Add new activities from remote
  const newActivities = remoteActivities.filter(a => !existingActivityIds.has(a.id));
  
  if (newActivities.length === 0) {
    return localActivities; // No new activities to add
  }
  
  // Combine local and new activities
  const combinedActivities = [...localActivities, ...newActivities];
  
  // Sort by timestamp
  combinedActivities.sort((a, b) => 
    new Date(a.timestamp).getTime() - new Date(b.timestamp).getTime()
  );
  
  // Limit size if needed
  if (combinedActivities.length > MAX_ACTIVITY_LOG_SIZE) {
    combinedActivities.splice(0, combinedActivities.length - MAX_ACTIVITY_LOG_SIZE);
  }
  
  // Save combined activities
  await secureStorage.set('device_activities', JSON.stringify(combinedActivities));
  
  return combinedActivities;
}
```

## Privacy Considerations

Balance security monitoring with user privacy:

1. **Transparency**: Clearly explain what activities are tracked and why
2. **Consent**: Get user consent before enabling activity tracking
3. **Minimization**: Only collect necessary information
4. **Retention Policy**: Automatically delete old activity logs
5. **Local Storage**: Keep activity logs in secure local storage

## Security Considerations

### Activity Log Protection

Protect the integrity of activity logs:

1. **Tamper Protection**: Implement mechanisms to detect tampering
2. **Secure Storage**: Store activity logs in secure storage
3. **Access Control**: Restrict access to activity logs
4. **Backup**: Regularly back up activity logs

### Alerting

Implement alerting for suspicious activities:

```javascript
async function checkForSecurityAlerts() {
  const anomalies = await detectAnomalies();
  
  // Filter for high-severity anomalies
  const highSeverityAnomalies = anomalies.filter(a => a.severity === 'high');
  
  if (highSeverityAnomalies.length > 0) {
    // Show alert to user
    showSecurityAlert(highSeverityAnomalies);
    
    // Log security event
    await logSecurityEvent({
      type: 'security_alert',
      anomalies: highSeverityAnomalies,
      timestamp: new Date().toISOString()
    });
  }
}
```
