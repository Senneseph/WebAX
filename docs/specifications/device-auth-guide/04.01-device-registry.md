# Device Registry

## Introduction

The device registry is a central data structure that maintains information about all paired devices in a device group. It serves as the source of truth for device management operations and enables the owner device to control access to the application.

## Registry Structure

The device registry should contain:

1. **Device List**: Array of device objects with metadata
2. **Last Updated**: Timestamp of the last registry update
3. **Version**: Registry version number for synchronization
4. **Owner Device ID**: Identifier of the owner device

Example registry structure:

```javascript
{
  devices: [
    // Array of device objects
  ],
  lastUpdated: "2023-07-15T10:30:00Z",
  version: 42,
  ownerDeviceId: "device-uuid-123"
}
```

## Device Metadata

Each device in the registry should include comprehensive metadata to facilitate management and security:

```javascript
{
  id: "device-uuid-123",           // Unique device identifier
  name: "John's iPhone",           // User-friendly name
  type: "mobile",                  // Device type (mobile, tablet, desktop)
  createdAt: "2023-07-15T10:30:00Z", // When the device was paired
  isOwner: false,                  // Whether this is the owner device
  lastActive: "2023-07-15T14:45:00Z", // Last activity timestamp
  publicKey: "base64-encoded-key", // Public key for secure communication
  status: "active"                 // Device status (active, inactive, revoked)
}
```

## Implementation

### Registry Class

A dedicated class for managing the device registry provides a clean API for registry operations:

```javascript
class DeviceRegistry {
  constructor() {
    this.secureStorage = getSecureStorage();
  }

  async initialize() {
    await this.secureStorage.initialize();

    // Check if registry exists
    const registryJson = await this.secureStorage.get('device_registry');

    if (!registryJson) {
      // Create new registry with current device as owner
      const deviceMetadata = await this.getCurrentDeviceMetadata();

      const registry = {
        devices: [deviceMetadata],
        lastUpdated: new Date().toISOString(),
        version: 1,
        ownerDeviceId: deviceMetadata.id
      };

      await this.secureStorage.set('device_registry', JSON.stringify(registry));
      return registry;
    }

    return JSON.parse(registryJson);
  }

  async getRegistry() {
    const registryJson = await this.secureStorage.get('device_registry');
    return registryJson ? JSON.parse(registryJson) : null;
  }

  async updateRegistry(registry) {
    registry.lastUpdated = new Date().toISOString();
    registry.version += 1;
    await this.secureStorage.set('device_registry', JSON.stringify(registry));
    return registry;
  }

  async getCurrentDeviceMetadata() {
    const deviceId = await this.secureStorage.get('device_id');
    const deviceName = await this.secureStorage.get('device_name');
    const isOwner = (await this.secureStorage.get('is_owner')) === 'true';
    const publicKey = await this.secureStorage.get('public_key');

    return {
      id: deviceId,
      name: deviceName,
      type: detectDeviceType(),
      createdAt: new Date().toISOString(),
      isOwner: isOwner,
      lastActive: new Date().toISOString(),
      publicKey: publicKey,
      status: 'active'
    };
  }

  async getDeviceById(deviceId) {
    const registry = await this.getRegistry();
    return registry.devices.find(d => d.id === deviceId);
  }

  async addDevice(deviceMetadata) {
    const registry = await this.getRegistry();

    // Check if device already exists
    const existingIndex = registry.devices.findIndex(d => d.id === deviceMetadata.id);

    if (existingIndex >= 0) {
      // Update existing device
      registry.devices[existingIndex] = {
        ...registry.devices[existingIndex],
        ...deviceMetadata,
        lastActive: new Date().toISOString()
      };
    } else {
      // Add new device
      registry.devices.push(deviceMetadata);
    }

    return this.updateRegistry(registry);
  }

  async removeDevice(deviceId) {
    const registry = await this.getRegistry();

    // Check if trying to remove owner device
    const deviceToRemove = registry.devices.find(d => d.id === deviceId);

    if (deviceToRemove && deviceToRemove.isOwner) {
      throw new Error('Cannot remove owner device');
    }

    // Remove device
    registry.devices = registry.devices.filter(d => d.id !== deviceId);

    return this.updateRegistry(registry);
  }

  async updateDeviceStatus(deviceId, status) {
    const registry = await this.getRegistry();
    const deviceIndex = registry.devices.findIndex(d => d.id === deviceId);

    if (deviceIndex >= 0) {
      registry.devices[deviceIndex].status = status;
      registry.devices[deviceIndex].lastActive = new Date().toISOString();
      return this.updateRegistry(registry);
    }

    throw new Error('Device not found');
  }

  async updateDeviceLastActive(deviceId) {
    const registry = await this.getRegistry();
    const deviceIndex = registry.devices.findIndex(d => d.id === deviceId);

    if (deviceIndex >= 0) {
      registry.devices[deviceIndex].lastActive = new Date().toISOString();
      return this.updateRegistry(registry);
    }

    throw new Error('Device not found');
  }

  async renameDevice(deviceId, newName) {
    const registry = await this.getRegistry();
    const deviceIndex = registry.devices.findIndex(d => d.id === deviceId);

    if (deviceIndex >= 0) {
      registry.devices[deviceIndex].name = newName;
      return this.updateRegistry(registry);
    }

    throw new Error('Device not found');
  }
}
```

## Secure Storage

The device registry must be stored securely to prevent unauthorized modifications. Use the secure storage mechanism described in the [Device Setup](./02-device-setup.md) section.

## Synchronization

The device registry needs to be synchronized across all devices in the group. This is covered in detail in the [Jcule Integration](./05-jcule-integration.md) section, but key considerations include:

1. **Version Tracking**: Each update increments the registry version
2. **Conflict Resolution**: Handle conflicts when multiple devices update the registry
3. **Partial Updates**: Support merging partial updates to minimize data transfer
4. **Validation**: Verify that registry updates come from authorized devices

## Security Considerations

### Registry Integrity

Protect the integrity of the registry:

1. **Digital Signatures**: Sign the registry with the owner device's private key
2. **Validation**: Verify signatures before applying registry updates
3. **Access Control**: Only allow the owner device to make certain modifications

### Privacy Considerations

The device registry contains sensitive information:

1. **Minimize Data**: Only store necessary information
2. **Local Storage**: Keep the registry in secure local storage
3. **Transmission Security**: Encrypt the registry during transmission
